# Jome

> Jome is a real estate technology marketplace for buying new construction homes "in the age of AI." Buyers search and compare new-construction homes and communities from multiple builders, view pricing and builder incentives, instantly book home tours, and get AI-powered recommendations, with new-home experts guiding them from contract to closing. Licensed brokerage operating across 18+ U.S. metros. Backed by Techstars. Jome publishes no public API or developer program; this file is generated by the API Evangelist enrichment pipeline from its public web presence.
